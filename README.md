* **Beschrijving van het project:** Een volledige, responsieve en interactieve e-commerce productpagina voor de Nikon Z5 camera, gebaseerd op een webshop-ontwerp. Het project omvat een semantische HTML5-structuur, modulaire CSS3-styling (Flexbox en CSS Grid) en een schone, overzichtelijke codeopbouw met Git/GitHub versiebeheer.
* **De reden waarom je dit project wilt maken:** Ik vond het erg interessant om zo'n webshop te maken en ik vind dit project erg goed voor mijn portfolio.
